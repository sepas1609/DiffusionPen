# DHSE Monetization, Go-to-Market & Unit Economics (Chapter 24)

## 1. Pricing Tiers

| Tier | Price | Target Persona | Key Feature Entitlements |
|---|---|---|---|
| **Free** | $0 | K-12 students, casual users | Single handwriting profile, Canvas 2D rendering, standard steganographic watermark, community presets. |
| **Pro** | $9 / month | University students, graphic designers | Up to 5 encrypted profiles, WebGPU acceleration, 3D WebGL Realism Studio, custom export presets. |
| **Teams** | $19 / seat / mo | Design studios, executive offices | 25 shared team profiles, priority rendering queues, developer REST API access, brand consistency packs. |
| **EDU Site License** | $2 / student / yr | Universities & academic departments | Unlimited student profiles, Canvas LMS integration, KaTeX exam batch renderer, bulk onboarding. |
| **Enterprise** | Custom ($10k - $100k) | Legal tech, enterprise publishers | On-premises VPC self-hosted deployment, custom security compliance audits, dedicated SLA. |

## 2. Unit Economics (From Roadmap v2 Model)

- **Pro Tier**: LTV = $280, CAC = $24, **LTV / CAC = 11.7x**, Payback period = 2.7 months.
- **Teams Tier**: LTV = $580, CAC = $180, **LTV / CAC = 3.2x**, Payback period = 9.5 months.
- **EDU Site License**: LTV = $6 - $60 / student, CAC = $400, **LTV / CAC = 15.0x**, Payback period = 24 months.
- **Enterprise**: LTV = $30k - $300k, CAC = $12,000, **LTV / CAC = 25.0x**, Payback period = 12 months.
- **Gross Margin**: Consistently **95% - 98%** due to client-heavy Wasm edge compute offloading cloud GPU costs.
